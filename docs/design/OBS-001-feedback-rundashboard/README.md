## 走查板分区

| 区 | 内容 | 覆盖状态 |
| -- | ---- | -------- |
| A  | 对话消息反馈：员工消息 hover 出 👍/👎；已反馈态常驻 + 撤销/切换 | — |
| B  | 👎 评语弹层（可选 ≤1024 字，进反馈看板） | — |
| C  | /runs 运行观测页：页头统计卡 ×4（count-up）+ 状态过滤 Tab + 留痕表格（状态 pill/时长/token/会话链接）+ 失败行错误透出 | — |
| C2 | 留痕空态（引导发起对话） | — |

## 关键设计决策

1. **反馈只挂员工消息**（用户消息无操作区）；PUT upsert 语义（重复点按=切换，撤销=删除行）。
2. **看板最小口径**（蓝图 S2）：今日调用 / 7 日成功率 / 平均时长 / 7 日 token——放 /runs 页头，不单独菜单。
3. **失败原因必须透出**（rules/react-nextjs §5.7）：FAILED 行展开显示 error 原文（mono，danger 语义）。
4. 导航新增「运行观测」入口（AppShell）。
