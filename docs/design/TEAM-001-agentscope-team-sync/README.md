## 关键设计决策（对照规格 §2）

1. **本地为主数据（local-master）**：本地 Team 是组织管理事实源；上游 AgentScope team 是运行面投影（`asTeamId` 关联，schema 已预留）。上游无成员列表概念，成员参与运行时不在本期（蓝图 R6）。
2. **同步失败不阻塞本地**：上游不可达时本地操作照常成功，详情页横幅透出真实错误 + 手动重试（rules/observability §4.3 外部调用失败必须可见）。
3. **任务只读浅映射**：任务 Tab 为 agent-tasks 只读列表（R6 口径：任务列表 + 状态）；创建/分派去 AgentScope 控制台。
4. **删除留档**：上游无 DELETE 端点（实测 404），本地软删 + 确认文案明示「运行面保留存档」。
