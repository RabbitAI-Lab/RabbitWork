## 关键设计决策

1. **检索口径降级**（2026-10-22 实证）：AgentScope 实例无知识端点（5 个候选路径全 404）→ 按蓝图 §9-R3 降级自建；首期 **pg 关键词检索（切片级 ILIKE + 命中数排序）**，向量检索（pgvector + embedding）随 MODEL/AI Provider 规格落地后接入——R-VECTOR 登记于规格。
2. **切片存储**：新表 `knowledge_chunks`（随本规格一次建齐——知识域首份规格补齐场景，同 TEAM-001 先例）。
3. **摄取同步化**：单机模式上传后同步切片（≤2MB 秒级），IngestJob 留痕供审计；异步化随 BullMQ 任务体系。
4. 中文全文：PG 内建无中文分词（zhparser 不可用于 embedded-postgres），关键词切片级检索为准；规格登记局限。
