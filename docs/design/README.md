# 高保真原型目录（AGENTS.md 门禁 2）

每个 UI 功能点的**高保真原型**产出于本目录：`design/{MODULE}-NNN-{slug}/`（静态 HTML+Tailwind 或 Storybook story，可浏览器打开走查）。

规则（AGENTS.md 门禁 2 / 模板 §3）：

1. 高保真原型的**产出必须先于对应功能的编码**——任务清单中「产出原型」必须排在编码之前；禁止原型未产出即编码、禁止「开发完再补原型」。
2. 规格元信息「高保真确认」字段：`确认人 / 确认日期 / 原型链接`；未人工确认（`待确认`）编码不得开始。**人工确认不可下放给 AI**（rules/ai-collaboration §5）。
3. 确认后交互变更 → 更新原型并**重新确认**，状态回到 `待确认`。
4. 纯后端/引擎类规格以「接口契约评审」替代高保真（OpenAPI/事件流 schema 人工确认视为通过）。
5. 实现完成后必须与原型**逐项走查**（布局/交互/各状态/边界/裁剪），走查批次登记（走查①②③…）；差异要么回改实现、要么更新原型并登记「勘误 N」（勘误记在本目录对应 README，可追溯）。
6. 每个原型目录附 `README.md`：确认记录、走查批次、勘误登记。
