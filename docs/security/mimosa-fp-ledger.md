## 使用说明

1. **不得为消音而绕过门禁**（禁改插件/禁全局禁用 hook）；medium 级须向用户说明风险并取得确认后放行。
2. 判定误报必须走三命题法完整证据链（汇聚点固定 / 源头自产 / 敌意输入实验 + 汇聚点实放），缺一不可。
3. **根治优先**：能按 rules/security §8.6 三类已实证形态改代码消链的，先改代码（行为等价、可测），台账只登记无法结构化消除的。
4. 「顺手加固观察」栏记录核实过程中发现的稳健性问题（非安全），登记后必须排期，不得以"误报"为由忽略。
